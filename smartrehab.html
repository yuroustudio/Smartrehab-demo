SMARTREHAB 智慧預健 · 個人專題

讓復健，不只發生在診所裡。

智慧預約 × 居家復健 × 復健追蹤

一個免下載、免密碼的 Web App，可從 LINE 直接開啟。病患離開診所後仍有明確的居家指引，診所也看得到院外的復健數據。

主講人：陳諭柔

專案背景

院內診察精準，院外追蹤斷線。

病患在診所完成診斷與徒手治療，回家後卻缺少居家指引與運動追蹤，治療效果接不起來。SmartRehab 把院內與院外接成同一條照護線。

病患端

臨床追蹤斷線，療程中途中斷

離院後不知道怎麼做居家訓練，進入運動迷惘期。痛感減輕就以為痊癒，又看不見復健進度，最後在療程中期永久中斷。

診所端

行政效率遇到瓶頸

櫃檯同時要接待與接電話。預約與改約靠人工電話和紙本、試算表核對，提醒容易遺漏，也容易發生溝通爭議。

傳統模式與 SmartRehab 的差別

傳統診所營運模式SmartRehab 智慧預健
預約與改約單筆耗時 10 分鐘至 1 天，靠人工電話反覆確認時段。1 分鐘內自動完成，病患在線上自助預約與改約。
到診提醒人工電話與紙本核對，提醒不穩定，容易引發到診爭議。系統自動發送到診提醒，溝通有軌跡，爭議消失。
人力配置櫃檯被重複的改約與提醒工作綁住。免除人工提醒，櫃檯人力轉去服務現場病患。

雙向省時與商業模式

病患端：極簡預約＋視覺導引 無縫完成預約，拿到標準化運動指引，使用門檻降到最低。
診所端：數據同步＋免人工提醒 即時掌握病患離院後的復健數據，同時釋放櫃檯行政壓力。
B2B2C 診所訂閱制 診所按月付費訂閱，病患完全免費。診所有明確的投資報酬，病患沒有採用門檻。
提升留存率

讓病患持續看見進步，延長單一療程週期。

降低中斷率

消除迷惘期與假性痊癒的誤判。

提高單日容載量

改約溝通時間縮短 90% 以上。

系統架構與技術選型

輕量、無縫，點開就能用。

醫療科技產品初期，用戶獲取成本與部署效率決定成敗。系統採用免下載、免帳號密碼的 Web App 與 LINE 嵌入式瀏覽器，把使用摩擦降到零。

FRONTEND 前端介面

HTML5 / JS / SVG

跨平台相容。向量 SVG 可綁定 DOM 事件，用來渲染高解析度、可互動的人體圖譜。

BACKEND 後端 API

Google Apps Script RESTful API

Serverless 架構，以 JSON Payload 傳輸資料，不必架設伺服器，維運單純。

ARCHITECTURE 整合架構

Serverless 無伺服器

沒有伺服器維護負擔，可彈性擴充，前端與 API 之間即時、輕量地傳輸資料。

AI 協作開發流程（5–6 週完成 MVP）

需求分析

訪談 2–3 位治療師或櫃檯人員、2–3 位中斷療程的病患，用親和圖歸納出「行政核對耗時」與「居家迷惘期」兩大斷點，並建立 Persona（上班族陳先生）。

流程設計

比較原生 App 與 Web App / LINE 嵌入的轉換率，定案輕量 Web 體驗，畫出病患與診所的雙向流程。

功能規劃

用艾森豪矩陣與 User Story Mapping 切出 MVP：智慧預約、居家復健、復健追蹤。

全端開發與除錯

用 AI 撰寫 API 測試腳本，解決行動端 SVG 觸控偏位與 Promise 鏈式調用異常，並把 AI 當作隨時可問的 Code Reviewer。

MVP 核心功能

三個模組，接成一個復健閉環。

預約鎖定病灶部位與看診時段
居家訓練跟著導引完成每日處方
追蹤回傳疼痛與遵從率，回診調整

模組一 · SMART BOOKING & VISUAL MAPPING

SVG 人體圖譜病灶匹配與自動化預約

觸發情境
首次預約或日常改約時，從 LINE 官方帳號或 Web App 連結進入。
系統邏輯
SVG 各肌肉與關節區域綁定 click / touchstart。點擊後擷取 data-region-id，自動帶入表單，以 JSON 送到 GAS API 寫入資料庫。後端計時器在診期前 24 小時呼叫推播 API 發出提醒。
產出
病患點選區域即高亮並填入「主訴部位」，預約後收到提醒卡片。診所端行事曆即時更新名單與病灶部位。
主訴部位（自動帶入） 請點選人體圖 region-id —
預約成功。系統會在看診前 24 小時發送到診提醒。

互動示範：點擊人體圖上的區域。

模組二 · HOME REHABILITATION & VISUAL GUIDANCE

視覺化居家運動導引與休息計時器

觸發情境
病患在院外開啟系統，點擊「開始今天復健」。
系統邏輯
依病患 ID 讀取治療師開立的處方陣列（動作影片或圖示 URL、目標組數、每組次數、組間休息秒數），由狀態機控制流程。Rest Timer 歸零時觸發音效與視覺提示，完成後打包總執行時間與組數。
產出
清楚展示正確動作與注意事項，加上動態倒數休息計時，幫病患走出「不知道回家能做什麼運動」的迷惘期。
準備中→動作執行→組間休息→下一組 / 完成

互動示範：處方為 3 組、每組休息 30 秒（示範用，已縮短動作時間）。

模組三 · CLINICAL TRACKING & ANALYTICS

VAS 疼痛趨勢圖與遵從率熱力圖

觸發情境
病患完成每日居家訓練後，自動跳出 VAS 疼痛評估；治療師開啟病患健康檔案時也會看到。
系統邏輯
病患滑動量表輸入 VAS（0 為無痛，10 為劇痛）。前端把「VAS 分數＋完成時間戳記＋運動完成率」傳到 GAS API 寫入雲端，再渲染 VAS 折線圖與近 30 天遵從率熱力圖。
產出
病患端與診所端看到同一份圖表，消除資訊不對稱，讓病患看見自己的進步，不因假性痊癒而中斷療程。
近 30 天遵從率未做全做

示範資料，非真實病患紀錄。拖曳量表可改變最後一天的 VAS。

未來擴展藍圖

從被動復健，走向主動日常預健。

長期目標是把健康管理放進日常生活，把服務延伸到亞健康族群，做成高黏著度的個人化預防醫學生態系。

日常預健花園

把每天完成的復健運動轉成花園植物的養分，用輕量互動降低養成習慣的心理負擔。

點數換禮獎勵

完成居家運動或健康打卡累積預健點數，可兌換診所自費項目折抵券或健康週邊商品。

居家復健挑戰賽

針對已康復或亞健康族群，推出主題式挑戰，例如「辦公室久坐肌群激活 14 天賽」。
